This release contains the complete current Yahtzee Coach repository.

STEP 1 — RUN THE ONE-TIME SUPABASE MIGRATION
1. In this release package, open v43b_phase2e_migration.sql.
2. In Supabase, open your Yahtzee Coach project -> SQL Editor -> New query.
3. Copy/paste the entire migration file into the editor.
4. Click Run.
5. Expected result: Success. No rows returned.

The migration is safe to run more than once. It allows saved Daily choices to be revised only before final submission; completed attempts remain immutable.

STEP 2 — UPLOAD THE FULL CURRENT APP TO GITHUB
1. Open the UPLOAD_TO_GITHUB folder.
2. In GitHub, open the yahtzee-coach repository root.
3. Choose Add file -> Upload files.
4. Select ALL files inside UPLOAD_TO_GITHUB and upload them together.
5. Commit directly to main.
